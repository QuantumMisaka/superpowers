Probe root: `/tmp/codex-task6-runtime-smoke-20260731T091909Z`

Decision: `provider-per-session`

## Method

Four fresh `codex exec --ephemeral --json` sessions used separate empty work
directories. Every command was guarded by
`timeout --signal=TERM --kill-after=15s 600s`; no more than two commands ran
concurrently. Each probe directory preserves:

- `command.txt`, `profile.txt`, `started-at.txt`, `finished-at.txt`, and
  `exit-status.txt`;
- raw `events.jsonl` and `stderr.log`;
- `final.txt` when Codex produced a final response; and
- `evidence-fields.txt`, generated by recursively listing event types and
  fields whose keys contain `model`, `provider`, `agent`, `role`, or `thread`.

## Decision

Mode: provider-per-session

At least one native cross-provider direction failed. The default profile
exposes five GPT engineering/review roles. The Bailian profile replaces every
generic slot with Qwen and adds context analyst plus document writer, exposing
seven Qwen roles without retaining active GPT children. Cross-model review uses
a file-based review package opened in a separate profile session. Nested
`codex exec` orchestration is not enabled.

The active registration mapping is:

| Slot | Default profile | Bailian overlay |
|---|---|---|
| `routine_worker` | `agents/gpt/routine-worker.toml` | `agents/qwen/routine-worker.toml` |
| `standard_worker` | `agents/gpt/standard-worker.toml` | `agents/qwen/standard-worker.toml` |
| `task_reviewer` | `agents/gpt/task-reviewer.toml` | `agents/qwen/progress-reviewer.toml` |
| `final_reviewer` | `agents/gpt/final-reviewer.toml` | `agents/qwen/document-reviewer.toml` |
| `monitor` | `agents/gpt/monitor.toml` | `agents/qwen/monitor.toml` |
| `context_analyst` | not registered | `agents/qwen/context-analyst.toml` |
| `document_writer` | not registered | `agents/qwen/document-writer.toml` |

All twelve provider-specific role files remain installed and unchanged. The

The plan's literal absolute-path unittest form,
`python -m unittest -v /home/james/.codex/tests/test_agent_matrix.py`, is not
accepted by the installed Python 3.13.13 or `/usr/bin/python3` 3.12.3; both
interpret `/home/james/` as a module and error before discovery. Running the
same suite from its directory as `python -m unittest -v test_agent_matrix.py`
is the recorded successful equivalent.

## Remaining concerns

- The runtime failure is at the observable spawn/child-response boundary. A
  later Codex build could change tool invocation or expose backend fields, so
  native cross-provider mode should be reconsidered only with a new four-probe
  record.
- Every fresh session also emitted warnings that legacy generic Agent TOMLs
  lack a `description`. Those legacy files and role prompts are outside Task 6
  ownership and were not changed.
- `/tmp` probe artifacts are intentionally retained through final review.
